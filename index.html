?Hướng dẫn lần đầu
1. Tạo Token
Vào github.com/settings/tokens/new → Note: apk-builder → Tích repo + workflow → Generate → Copy.
2. Tạo Repo
Vào github.com/new → Đặt tên (VD: apk-builder) → Không tích README → Create.
3. Nhập vào Bước 1
Token + Username + Repo → Lưu và kiểm tra.
4. Build
Nhập HTML → Thông tin app → Bắt đầu build → Đợi 2-3 phút → Tải APK.
